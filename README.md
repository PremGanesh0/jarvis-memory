# Jarvis Memory Vault

> Personal knowledge base and long-term memory for AI assistants.

## Structure

- `notes/` - General markdown notes
- `memory/` - Long-term memory entries
- `.agents/` - Agent configuration (skills, rules)

## Getting Started

Create notes in the `notes/` folder. Link them with `[[Note Name]]` syntax.
