# Jarvis Memory System

> Long-term memory for AI assistants. Store important facts, preferences, and learned knowledge here.

## How to Use

1. Add new memories as individual markdown files in `memory/`
2. Name files descriptively: `YYYY-MM-DD-topic.md`
3. Link related memories with `[[wikilinks]]`
4. Keep entries atomic — one fact per note when possible

## Memory Categories

- **User Preferences** - How the user likes things done
- **Project Knowledge** - Context about ongoing work
- **Learned Facts** - Things discovered through interaction
- **Decisions** - Important choices and their rationale
